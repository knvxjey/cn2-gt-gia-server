## CN2 GT 和 GIA：一条回程决定晚高峰

CN2 是中国电信的下一代承载网，AS4809。它分两个等级：GT 只有部分节点走 CN2，其余段落回落到普通 163 骨干，高峰期照样抖动；GIA 全程走 CN2 并有 QoS 保障。同一家商家，GIA 的价格能比 GT 贵一倍。

香港到内地物理距离近，机房延迟通常在 40~60ms，美国机房 130ms 以上，日本 70ms 以上。这是常见区间，实际数字取决于你本地的运营商和测试时段。有商家标称自家香港 CN2 国内延时 15~40ms，也有推广文章写电信 30ms、三网平均 30~50ms，这些都没有公布测试方法，只能当参考区间看，别当承诺。

自己验证的步骤，四步就够：

1. 找商家要测试 IP，不要只看他们给的测速截图。
2. 本地用 tracert 或 mtr 打这个 IP，看回程经过的 AS 号。全程 AS4809 是 GIA 的特征；中途跳回 AS4134 说明有段落走了 163 骨干。
3. 时间放在晚上 21:00 到 23:00，白天的路由没有参考价值。
4. 电信、联通、移动各测一次。联通方向看 AS9929，移动方向看 CMI 或 CMIN2，三条都优化过的才是常说的三网直连。

## 把 Mbps 换算成你能感知的速度

- 10Mbps ≈ 1.25MB/s
- 30Mbps ≈ 3.75MB/s
- 50Mbps ≈ 6.25MB/s

流量同理。500GB 月流量摊到每天约 16GB，一个纯文字博客用不完；3TB 摊到每天约 100GB，图片站和小型电商才需要考虑。

“不限流量”在市面上有两种截然不同的实现。一种是真不限、但把上行压到 6–13Mbps，纽特云 D 区就是从 6M 上行起步的。另一种是标称不限、超过阈值后限速到 1Mbps，这时候不限量已经没有意义。还有一类干脆按流量计费，用完就停，CstoneCloud 就明确写了流量用尽后服务暂停，而不是限速继续跑。三种模式对建站的影响完全不同，下单前问清楚是哪一种。

## 五个容易踩的地方

**共享带宽写成独享。** “100Mbps 带宽”这种描述不说明共享还是独享就没有意义，晚高峰几个人一起抢，实际到手可能只剩几 Mbps。香港 CN2 的带宽成本高，10–30Mbps 的独享比标称 100Mbps 的共享更实用。

**GT 当 GIA 卖。** 这两个词在中文页面上经常混用，价格差一倍，体验差一截。用上面那套路由追踪的方法验一次，比看任何文案都可靠。

**退款条款里的前提条件。** 常见写法是“24 小时内退款”，后面跟一句“IP 未被封”。这句前提意味着 IP 被封算用户侧责任，不给退。丽萨主机的口径是 48 小时无条件退款，宽松一些。退款窗口的长短直接决定你能不能先月付试一台。

**1G 内存只支持 Linux。** CstoneCloud 明确写了 1G 套餐仅支持 Linux，要装 Windows 得从 2G 起步。打算用宝塔面板加 Windows 的话，入门档直接跳过。

**IP 纯净度。** 做跨境电商、社媒运营、AI 工具访问的，IP 被标记过的话延迟再低也没用。这类需求要看的是 IP 属于机房段还是 ISP 段，下单前用测试 IP 查一下 ASN 和黑名单状态。

## 三类用途，三套参数

**建站，包括外贸独立站。** 内存是第一个门槛，1G 能跑 WordPress 加几个插件，2G 是从“能跑”到“跑得舒服”的分界。硬盘看是不是 NVMe 或 SSD 阵列，装环境、跑数据库的差别能感觉到。带宽 10Mbps 够文字站，有图有视频就上 30Mbps。香港机房不需要 ICP 备案，域名解析过去就能开。

**跳板与中转节点。** 这类用途的瓶颈几乎总在上行。多设备共用、长时间跑流量，6Mbps 上行会在几天内让你后悔。要么直接选上行 13Mbps 以上的档位，要么接受按流量计费但带宽更大的方案。流量估算上，个人轻度使用每月几百 GB 到 1TB，多人共用翻几倍。

**香港本土服务与流媒体。** 想要 TVB、Netflix 港区、Disney+，需要的是香港原生住宅或 ISP 属性 IP，机房 IP 一般解不开。丽萨主机有 HGC 和 iCable 两条双 ISP 家宽产品线专门做这个；普通三网直连的 CN2 套餐是 ISP 属性 IP，能兼顾延迟和部分本土服务。这一类需求里，IP 属性排在延迟前面。
